## ¿Qué es VIDA?

Una app cristiana para el día a día: leer la Biblia sin conexión, orar con guía, mantener una racha, recibir un versículo personalizado y compartir la fe — sin anuncios ni pago.

Pensada para quienes quieren crecer en Cristo con herramientas claras, contenido en español y una experiencia calmada.

## Navegación

| Pestaña | Contenido |
|---|---|
| **Inicio** | Mazo de cartas (VIDA · versículo del día · oración), racha, herramientas y Mini Arcade |
| **Biblia** | Lector offline Reina-Valera 1909 |
| **VIDA** | Tu versículo del mes (algoritmo según tu uso) |
| **Perfil** | Apariencia, actualizaciones y créditos |

## Funcionalidades

### En el inicio

| | |
|---|---|
| **Mazo de cartas** | Desliza hacia arriba: versículo VIDA, versículo del día y oración guiada |
| **Oración guiada** | Historia paso a paso: gratitud, arrepentimiento, alabanza, confianza y fe |
| **Racha espiritual** | Constancia diaria y mejor racha |
| **Crear imagen** | Fondos + texto bíblico para compartir |

### Biblia y estudio

| | |
|---|---|
| **Biblia RVR1909** | Offline, resaltados, tamaño de letra; otras versiones vía YouVersion |
| **Estudio bíblico** | Notas y estudios personales (en el dispositivo) |
| **Guardados** | Versículos y contenido que marcaste |
| **Situaciones difíciles** | Consejos y versículos por momento de vida |

### Compartir la fe

| | |
|---|---|
| **Evangelízate** | 10 guías: obras, sin Cristo, ateo, agnóstico, sufrimiento, objeciones, familia, religión, métodos y consejos |
| **Testimonios** | Lectura de testimonios |
| **Fuentes** | Living Waters, Billy Graham, Harvest, Camino de Romanos, Cru — la autoridad final es la Biblia |

### Comunidad y lugar

| | |
|---|---|
| **Comunidad** | Publicaciones, likes y comentarios (cuenta con nombre) |
| **Mapa de iglesias** | Buscar, agregar, “Yo asisto aquí” y direcciones |

### Widgets (Android)

| | |
|---|---|
| **Contra pecado** | Frase diaria en la pantalla de inicio |
| **Widget favorito** | Tu versículo (fondo por defecto o foto propia) |

### Mini Arcade (8 juegos)

Quiz · Riega y crece · Memorama · Ordena el versículo · Verdadero / Falso · Trivia · Camino del discípulo · **¿Quién lo dijo?**

### Ajustes

Apariencia (claro / oscuro / sistema, estilos Esmeralda · Océano · Ámbar · Pizarra, acento) · notificaciones locales · buscar actualizaciones desde GitHub Releases.
