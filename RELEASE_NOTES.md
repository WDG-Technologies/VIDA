- **Versión web** usable (Firebase Hosting)
- Mini Arcade **completo en web**: Quiz y Riega vía iframe HTML (además de los 6 juegos Flutter)
- Mapa con iglesias desde JSON local si Firebase no está disponible
- Crear imagen / compartir compatible web
- Branding web (título VIDA, colores esmeralda)
- **Evangelízate** ampliado y ordenado: Empieza aquí → Situaciones → Cerca de ti
- Incluye **0.9.21** (versículos del día, avisos Comunidad, seed iglesias, etc.)
